# Cantina da Faculdade — Trabalho NP2 (Desenvolvimento Mobile)

App em Flutter para pedir lanches da cantina: **peça e retire** no balcão ou **delivery**.

## Telas (pasta `lib/`)
- `home_page.dart` — cardápio
- `pedido_page.dart` — formulário do pedido + ViaCEP (recurso extra)
- `pedidos_page.dart` — lista de pedidos em tempo real (Firestore)
- `main.dart` — inicia o Firebase e o app
- `firebase_options.dart` — chaves do Firebase

## Como rodar
1. Clonar o repositório e abrir a pasta no VSCode.
2. `Ctrl+Shift+P` → **Pub: Get Packages**.
3. Escolher **Chrome** como dispositivo (canto inferior direito) e apertar **F5**.
